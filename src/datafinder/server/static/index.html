资源目录

指标、数据表、数据集：按主题、地域、资源类型筛选，每条都标明能不能下载。

目录只收录名称、口径与链接，不含数值。“可下载”表示有文件直链，图片类只能看、不能直接分析；“需生成”表示要通过接口取数，请在命令行用 datafinder get（或让 AI 助手通过 MCP）获取。

目录树

同一批资源的三种看法：按主题、按地域、按来源逐级展开，数字是当前条件下命中的资源数。

分类浏览

不用输入关键词：按领域、地区、机构类型层层点选，找到有这类数据的网站。

领域标签由名称、描述与主题自动归类，可能有偏差；"官方"指国际组织、国家级与地方政府发布；"开放程度"以原站为准。

中国统计

国家统计局官方数据库、31 个省级统计局、省市开放平台，一处点选。

国家统计局数据发布库 实验性

打开官网 ↗

13 个数据库，按“时间维度（月/季/年）→ 专业分类 → 指标”逐级展开。接口为试运行期、无正式文档，且有访问防护，所以分类按你的点击逐级加载并缓存，不会批量抓取。

省级统计局

官方网站直达。部分网站对自动访问返回拒绝，或从当前网络无法核验，已如实标注。

省市公共数据开放平台

这些平台的接口基本都需要注册、申请密钥后才能调用，所以这里只做导航并标明获取方式。
