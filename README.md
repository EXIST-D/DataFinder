# DataFinder

**多领域、多来源的找数入口，能下载的直接给。** 用关键词或一句话，找到数据在哪、怎么拿：能直接下载的给文件，需要通过接口取数的生成整洁表格，只有链接的给准确链接和获取方式。中文优先。

[MIT 许可](LICENSE) · Python ≥ 3.11 · 本地运行，无需 Docker / 数据库 / Node

## 项目定位

- **要解决的问题**：数据散落在统计局、部委、年鉴、开放平台、科研仓库里，找一张表要翻很多站点；找到之后还要自己判断能不能下、怎么下。
- **要做成什么**：一个**多领域聚合检索**工具——统一的目录、统一的筛选方式、统一的"怎么拿"。给人用（命令行、本地网页），也给 AI 助手用（MCP）。
- **现在到哪了**：v0.0.x，早期开发。**目前只接入了一个领域：中国官方统计，这只是第一步**。框架按"核心通用、领域插件化"搭建，新领域只需加一个领域包（适配器 + 分类词典 + 术语词表），不改核心；`tests/architecture` 自动守护这条边界。
- **不做什么**：不存任何数值（目录只含名称、口径、链接）；不替你下载（只在你明确要求时才下）；不绕过站点的访问防护。

## 它怎么组织数据

目录里每条是一个**资源**（指标、数据表、数据集、统计库、年鉴/普查版次、公报、门户……），用三个互相独立的**分面**描述：

| 分面 | 回答 | 例子 |
|---|---|---|
| **主题** | 关于什么 | 工业与制造业 › 工业增加值；人口；能源与碳排放…（可多选、有层级） |
| **地域** | 涉及哪里 | 全国 · 河北 · 港澳台 · 国际；区分"数据覆盖哪里"与"按哪一级报告（省/地市/县）" |
| **资源类型** | 是什么形态 | 指标 · 数据表 · 数据集 · 统计公报 · 数据发布 · 普查数据 · 门户… |

另有观测期、频率、核验状态等辅助筛选，以及每条结果都标明的**获取方式**：

| 获取方式 | 含义 | `datafinder get` 做什么 |
|---|---|---|
| ⬇ **download** 可直接下载 | 目录里登记过的文件直链 | 下载到本机，附清单（来源、时间、体积、sha256、许可） |
| ⚙ **generate** 需要生成 | 没有现成文件，要经接口实时取数 | 取数 → 整洁长表 → 导出 CSV/Excel，附描述统计与覆盖检查 |
| ↗ **link** 只有链接 | 网页、图片、需登录/申请、站点拒绝机器人 | 给出链接与获取方式，不下载 |

几条贯穿始终的原则：**未知不等于满足**（宽松模式返回并标注缺什么，严格模式不算）；**出版年不是观测期**；**发布机构所在地不是数据覆盖地**；**标题推断的粒度不冒充已验证**；**图片能下载但不能直接分析**。

## 安装要求

| 项 | 要求 |
|---|---|
| Python | ≥ 3.11 |
| 工具 | [uv](https://docs.astral.sh/uv/)（推荐；也可用 pip） |
| 系统 | 开发与测试在 macOS；Linux / Windows 理论可用，未验证 |

| 网络 | 首次安装快照要访问 GitHub；实时取数、抓取目录要访问来源站点（国内站点可能受网络环境影响） |

## 快速开始

```bash
uv tool install git+https://github.com/EXIST-D/DataFinder

datafinder sync                 # 一次：门户库（约 7MB）
datafinder index pull           # 一次：资源目录快照（约 45MB，几秒装好）
datafinder search "工业增加值" -r 河北      # 找
datafinder get '<resource_id>' -r 河北 --yes   # 拿（不加 --yes 只预览）
```

从源码运行：`git clone` 后 `uv sync --extra dev`，命令前加 `uv run`。命令别名 `dfd`（不用 `df`，避免遮蔽系统的磁盘命令）。`datafinder doctor` 一键体检环境与网络。

快照只含元数据，是维护者定期发布的。想自己抓取或补全某个来源用 `datafinder index build [来源]`（串行限速、可中断续跑）；本地目录比快照新时 `pull` 会拒绝覆盖（`--force` 才替换，旧库备份为 `catalog.db.bak`）。

## 使用

### 命令行

```bash
# 找
datafinder search "工业增加值" -r 河北 -k indicator            # 河北能取数的指标
datafinder search "规模以上工业增加值" -r 山东 -k table -d download   # 山东年鉴里可下载的表
datafinder search -t cnstat.population -r 辽宁 -k table         # 只用筛选浏览
datafinder search "人口" --from 2015 --to 2020 --strict         # 严格模式：观测期未知的不算
datafinder facets                                               # 合法的主题、地域、类型与获取方式（带计数）
datafinder inspect '<resource_id>' -c                           # 层级、分发入口、怎么获取
datafinder plan "工业质量体系评价" -r 河北省                      # 研究选题的找数方案：指标、数据表、公报、官方入口、统计建议

# 拿（默认只预览；--yes 才执行）
datafinder get '<resource_id>' -r 河北 -r 北京 --start 2015 -o 工业增加值.xlsx --yes
datafinder describe 工业增加值.csv                               # 描述统计

# 维护
datafinder index pull | status | build [来源] | snapshot       # 目录的安装、状态、抓取、打包
datafinder datasets "air quality"                               # 实时查外部数据平台（Zenodo、DataCite、各国开放数据…）
```

取数输出是**整洁长表**（期别、地区、指标、数值、单位，一行一个观测值），CSV 带 BOM、Excel 直接打开不乱码；默认保存到 `~/.datafinder/exports/`，每个文件旁有 `*.manifest.json`。取数后还给**覆盖检查**：期望的 地区×指标×期别 里实际取到多少、缺哪些。时间格式：年度 `2015`、月度 `201501`、季度 `202401`。

### 本地网页

`datafinder serve`（只监听本机）：**资源目录**（主题磁贴 + 地域/类型/获取方式筛选 + 严格模式）、**搜索**（实时查外部平台）、**门户目录**、**中国统计**（国家统计局数据库逐级浏览与取数）、**检索入口**。网页不执行下载，只给出可复制的 `datafinder get` 命令；完全离线可用，严格 CSP。

### 给 AI 助手用（MCP）

```bash
datafinder mcp --print-config    # 打印可粘贴到 Cursor / Claude Desktop / Claude Code 的配置
```

九个工具，按能力分层，**工具名里没有领域词**：

| 层 | 工具 | 作用 |
|---|---|---|
| L0 上下文 | `facets` `sources` `status` | 合法的分面取值；有哪些来源；目录状态与下一步提示 |
| L1 发现 | `search` `plan` | 多分面检索（不联网）；研究选题的找数方案 |
| L2 检视 | `inspect` | 一个资源的层级、分发入口、怎么获取 |
| L3 获取 | `fetch` `download` | **默认只预览**，`confirm=true` 才联网并写文件 |
| L4 后处理 | `describe` | 对已导出文件做描述统计 |

工具是确定性的、不调用大模型；理解题目、拆指标体系、写方案由助手自己做。错误统一为 `[错误码] 原因（下一步：…）`。`fetch` 只能写进导出目录，`download` 只接受目录里登记过的链接（拒绝内网地址，限制重定向与体积）。

## 已接入：中国官方统计

| 内容 | 规模与形态 | 获取方式 |
|---|---|---|
| **国家统计局发布库** | 13 个库、约 8 万个指标，月/季/年度、分省、主要城市、港澳台、国际 | ⚙ 实时取数 |
| **统计年鉴** | 中国统计年鉴 2005–2025；山东、辽宁、河南、上海省级年鉴（约 3 万张表）；广东、湖北整本下载 | ⬇ xls / 网页表 / 图片 |
| **普查资料** | 第七、六次人口普查，第一至五次经济普查（约 1500 张表） | ⬇ 多数有 xls |
| **统计公报与数据发布** | 国家统计局年度/普查公报、月度季度发布与解读（约 2000 条）；各省统计局、部委的"统计公报/统计数据"栏目 | ↗ 网页为主，附件可下 |
| **官方入口** | 31 个省级统计局、28 个部委等机构的网站入口与栏目 | ↗ 链接 |

**覆盖现状（如实）**：栏目条目的收录取决于站点是否可访问、栏目页能否被通用解析。在一个国内网络环境实测，约 1/3 的省级统计局和 4 个部委被收录到条目，其余因超时、拒绝（HTTP 403/412）或动态页而只有入口；北京、河北、四川、黑龙江年鉴同样受网络影响。换个网络运行 `datafinder index build site` / `yearbook` 通常可以补全。**国家统计局发布库是实验性的**：接口无正式文档且有访问防护，只在你主动抓取/取数时访问，串行限速，遇防护即停，**不重试、不绕过**。

## 效果评估与局限

```bash
datafinder bench topics [--holdout|--public]   # 选题验收：找数方案是否给出该有的门户/指标/数据表/公报
datafinder bench facets [--holdout]            # 分面检索验收：筛选语义，尤其是"必须不出现"的误导项
datafinder bench run                           # 排序基准：14 条中文问句 + 约 580 条标注
```

- 开发集（调参用）接近满分；自拟留出集约 90%；**公开来源选题集**（取自 CT2C-QA、统计建模大赛获奖选题、NTCIR 题型）第一次跑是 **59/76（78%）**，其中真正的公开题 73%。后者才更接近真实水平；主要缺口是术语词表和部委/省局网站的覆盖。
- 样本小、标注者是 AI，只能当方向性证据。方法、结果与留出集纪律见 [bench/README.md](bench/README.md)。

## 扩展与开发

| 想做什么 | 怎么做 |
|---|---|
| 新增一个领域 | 建 `domains/<id>/`（适配器 + 分类词典 + 术语词表 + `plugin.py`），先写验收集；见 [CONTRIBUTING.md](CONTRIBUTING.md) |
| 新增政府/机构网站栏目 | 在领域包 `data/sites.yaml` 加机构或栏目，无需写代码 |
| 新增年鉴/普查系列 | 在系列登记表加一条，选页面形态（`zk` / `tree` / `list`） |
| 新增 CKAN 类门户 / 中文词 / 统计术语 | `data/sources.yaml` / `lexicon.zh-en.yaml` / 领域包 `thesaurus.zh.yaml` 加一行 |
